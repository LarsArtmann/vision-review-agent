# M14 Performance Baseline — Journal-Bound Daemon Paths

**Created:** 2026-09-07 ~22:20 CEST
**Machine:** AMD Ryzen AI MAX+ 395 (32 threads), local NVMe, Go 1.26.7,
GOEXPERIMENT=jsonv2, commit `c2e34f9` (+benchmarks).
**Harness:** `internal/reviewd/perf_test.go` (committed). Reproduce with:

```bash
go test ./internal/reviewd -run '^$' \
  -bench 'BenchmarkReplay|BenchmarkPassSteady|BenchmarkAllEvents' \
  -benchmem -benchtime 5x
```

This is the FIRST recorded baseline — no pre-bump numbers exist, so no
pre/post-bump comparison is possible (plan F14.5 closes as not-applicable;
future bumps compare against THIS table).

## Results (-benchtime 5x, median-ish of 5 iterations)

| Benchmark                     | Journal scale                         | ns/op   | B/op   | allocs/op |
| ----------------------------- | ------------------------------------- | ------- | ------ | --------- |
| `BenchmarkReplay`             | 1 000 events (10 views × 50 passes)   | 21.1 ms | 66 MB  | 78 561    |
| `BenchmarkReplay10kEvents`    | 10 000 events (100 views × 50 passes) | 197 ms  | 67 MB  | 784 779   |
| `BenchmarkAllEvents10kEvents` | read+decode 10 000 events             | 47.5 ms | 22 MB  | 253 339   |
| `BenchmarkPassSteady`         | steady-state pass, 100 views all seen | 2.9 ms  | 4.6 MB | 19 083    |

## Reading the numbers

- **Replay scales linearly** (~20 ms per 1 000 events) and is
  read+decode-bound: raw `AllEvents` is ~48 ms of the ~197 ms 10k
  replay; the rest is fold + markdown render + file writes.
- **Steady-state pass is essentially free** (2.9 ms for 100 views; a
  real 216-view tree ≈ 6–7 ms). Pass cost is dominated by model calls
  on CHANGED views only (~20–30 s/view on CPU llama-server), which is
  the basis for the DiscordSync cadence math in TODO_LIST
  (~1.5–2 h worst-case first pass; later passes incremental).
- **Snapshot/v4 stays declined** (docs/DEPS.md ADR): replay is an
  on-demand operation (upgrade/recovery command), not a per-tick path.
  At ~200 ms per 10k events, a 1M-event journal would take ~20 s —
  that is the scale at which snapshots would start to matter.
