## Family-wide classes (fix once per repo, not per finding)

1. **scrollable-region-focusable (serious; 7 sites)** — scrollable `<pre>`/code
   panels and card bodies lack keyboard access. Fix: `tabindex="0"` on the
   scrollable element (and `aria-label` where it is a code sample).
   Affected: atomicwrite, cmdguard, go-output, gogenfilter, typespec-asyncapi.
2. **color-contrast on accent buttons/badges (serious; 6 sites)** —
   `.bg-accent`/`.text-bg-primary` pairs below 4.5:1 (white on violet).
   Affected: art-dupl, do-auditlog, gogenfilter, md-go-validator,
   typespec-asyncapi, learnings (Docusaurus theme + DocSearch).
3. **empty-table-header (minor; 9 sites)** — one empty `<th class="tracking-wider">`
   in a shared table component. Affected: art-dupl, branded-id, cleanwizard,
   dynamicmarkdown, emeet-pixyd, errorfamily, filewatcher,
   go-workflow-auditlog, templcomponents, md-go-validator.
