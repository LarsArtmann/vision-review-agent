# a2ui

Turn screenshots and design images into valid, interactive
[A2UI](https://a2ui.org/) surfaces, generated by any vision model.

A2UI is a protocol by which agents send declarative component descriptions
(not code) that clients render with their own native widgets. This package
implements the agent side for spec version v0.9.1.

```go
agent, _ := vision.NewAgent(vision.Config{Model: model})
img, _ := vision.LoadImageFromFile("mockup.png")

result, err := a2ui.Generate(ctx, agent, a2ui.GenerateOptions{}, img)
if err != nil {
    log.Fatal(err)
}

wire, _ := a2ui.MarshalJSONL(result.Messages) // JSON Lines for any A2UI client
```

What is inside:

- `Generate` — the vision bridge: images in, validated surface out (one
  `vision.AnalyzeStructured` call with a catalog-grounded prompt).
- `Compile` / `Decompile` — between the LLM-facing `SurfaceSpec` inference
  format and the official wire messages (both directions, lossless for
  compile-shaped streams).
- `Validate` / `Issues` — structural validation with typed error causes.
- Constructors for all 18 basic-catalog component kinds (`NewText`,
  `NewButton`, `NewTabs`, ...) for programmatic surfaces.
- `MarshalJSONL` / `UnmarshalJSONL` — the JSON Lines transport codec.

Conformance against the official v0.9.1 JSON schemas is machine-checked on
every test run; the schemas are pinned under `testdata/official/`.

Conceptual reference (formats, lifecycle, error taxonomy, known model quirks):
[docs/A2UI.md](../../../docs/A2UI.md). Official specification:
[a2ui.org/specification/v0_9_1](https://a2ui.org/specification/v0_9_1/).
